PORTFOLIO COMMAND — ID REPAIR

This tool rewrites the live portfolio/main Firestore document. It will not let you write until you have downloaded a backup and reviewed the dry run. Steps must be run in order.
Step 1 — Sign in

This page runs as its own Firebase app instance, so it needs its own sign-in (the same email and password you use for the app).

Step 2 — Back up

Loads portfolio/main and downloads it as JSON. Nothing is written.

Step 3 — Dry run

Scans for duplicate IDs and shows exactly what would change. Nothing is written.







  
Step 4 — Apply

  
Writes the repaired document back to Firestore. Enabled only after a backup and a dry run
     that found something to fix.
